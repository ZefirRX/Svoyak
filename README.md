# Quiz Helper — КЦСОН Московского района

WPF, .NET 10, EF Core 10, SQLite. Интерфейс основан на HTML и девяти экранах PDF.

## Запуск
Открыть `Svoyak/Svoyak.slnx` в Visual Studio с поддержкой .NET 10 и WPF, запустить проект Svoyak.
Командная строка: `dotnet run --project Svoyak/Svoyak.csproj`.

## Структура
- App.xaml — палитра и общие стили.
- MainWindow.xaml — меню, библиотека, редактор, команды, табло, вопрос и итоги.
- MainWindow.xaml.cs — навигация, библиотека и настройка команд.
- MainWindow.Editor.cs — редактирование шаблона и медиа.
- MainWindow.Game.cs — раунд, таймер, начисление и отмена очков.
- Models.cs / QuizDb.cs — сущности и EF mapping существующей БД (Database First).
- GameRepository.cs — чтение и транзакционное сохранение игр, настройки таймеров.
- ProjectorWindow — отдельное окно с вопросом, таймером и счётом без ответа.

## Данные
Исходная SQLite_Svoyak.db копируется к программе при сборке. Игры сохраняются в копии рядом с исполняемым файлом. Схема исходной БД не меняется; миграции и EnsureCreated не используются. Таймеры сохраняются в timers.json рядом с приложением. Команды, счёт и история текущей партии хранятся в памяти. Медиафайлы привязаны по абсолютному пути: при переносе проекта потребуется выбрать их заново.

## Проверка
`cd verification`, затем `dotnet run`. Проверка использует отдельную копию БД, проверяет сохранение и повторное сохранение игры и отрисовывает пять экранов в PNG.

## Ведущий и проектор
В Windows выбрать Win+P → «Расширить». Ведущий запускает игру на своём мониторе: приложение автоматически размещает экран игроков на другом мониторе без переключения фокуса. Управление и просмотр ответа остаются у ведущего. Кнопка «Показ на втором экране» повторно открывает показ, если он закрыт.
За неверный ответ снимается стоимость вопроса. Повторное списание с той же команды за тот же вопрос заблокировано. «Отменить последнее» возвращает списанные баллы и возможность ответить.
Кнопка показа работает и без второго монитора: экран игроков открывается в обычном перемещаемом окне. Кнопка «Удалить тему» удаляет выбранную тему с вопросами из редактируемого шаблона; для записи изменений в БД нажмите «Сохранить».
Экран игроков между вопросами показывает табло с темами и баллами. Сыгранные ячейки зачёркнуты, нажатия на табло игроков отключены. Выбор вопросов выполняется у ведущего.
