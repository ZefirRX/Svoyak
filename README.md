# Quiz Helper — КЦСОН Московского района

WPF, .NET 10, EF Core 10, SQLite. Интерфейс основан на HTML и девяти экранах PDF.

## Запуск
Открыть `Svoyak/Svoyak.slnx` в Visual Studio с поддержкой .NET 10 и WPF, запустить проект Svoyak.
Командная строка: `dotnet run --project Svoyak/Svoyak.csproj`.

## Структура
- App.xaml — палитра и общие стили.
- MainWindow.xaml — меню, библиотека, редактор, команды, табло, вопрос и итоги.
- MainWindow.xaml.cs — навигация, библиотека и настройка команд.
- MainWindow.Editor.cs — редактирование шаблона и медиа.
- GameSession.cs — состояние партии, начисление очков, штрафы и отмена действий.
- MainWindow.Game.cs / MainWindow.Board.cs — вопрос, таймер, табло и итоги у ведущего.
- MainWindow.Media.cs / AudioPlaybackSource.cs — воспроизведение и подготовка аудиофайлов.
- Models.cs / QuizDb.cs — сущности и EF mapping существующей БД (Database First).
- GameRepository.cs — чтение и транзакционное сохранение игр, настройки таймеров.
- ProjectorWindow — отдельное окно с табло, вопросом, таймером и счётом. После завершения вопроса показывает правильный ответ 4 секунды.

## Данные
Игры читаются и сохраняются в SQLite_Svoyak.db в корне репозитория. Debug и Release используют один файл. Схема исходной БД не меняется; миграции и EnsureCreated не используются. Таймеры сохраняются в timers.json рядом с приложением. Команды, счёт и история текущей партии хранятся в памяти. Медиафайлы привязаны по абсолютному пути: при переносе проекта потребуется выбрать их заново.

## Публикация одним EXE

Из корня репозитория выполните в PowerShell:

```powershell
dotnet publish .\Svoyak\Svoyak.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:DebugType=embedded -o .\artifacts\single-exe
```

Для распространения достаточно `artifacts\single-exe\Svoyak.exe`. При первом открытии игр приложение создаёт рядом с EXE рабочую копию встроенной БД. Для `Svoyak.exe` она называется `Svoyak.db`. Таймеры сохраняются в `Svoyak.timers.json`. Имена файлов данных зависят от имени EXE. Обновление EXE в той же папке с тем же именем сохраняет рабочую базу.

По умолчанию в сборку входит база из корня репозитория. Для публикации с другой базой передайте `-p:SeedDatabasePath="C:\папка\SQLite_Svoyak.db"` с абсолютным путём к её резервной копии.

## Перенос игр на другой компьютер

В меню «Редактор» нажмите «Экспорт CSV…». Файл содержит игры, описания, темы, вопросы, ответы, баллы и таймеры. Вопросы с медиафайлами переносятся текстом. Файлы можно заново прикрепить в редакторе.

На другом компьютере откройте «Редактор» → «Импорт CSV…» и выберите файл. Импорт добавит игры к существующей библиотеке. Повторный импорт добавит копии игр. Если нужно подготовить CSV вручную, используйте экспорт как шаблон и сохраните заголовки столбцов. Экспорт использует UTF-8 с BOM и разделитель `;`. При импорте также поддерживается разделитель `,`. ID должны быть уникальны внутри файла, а ID родителя — меньше ID дочерней записи.

## Проверка
`cd verification`, затем `dotnet run`. Проверка использует отдельную копию БД, проверяет сохранение игры, начисление и отмену очков, показ ответа на проекторе и сохраняет снимки экранов в `verification/artifacts`.

## Ведущий и проектор
В Windows выбрать Win+P → «Расширить». Ведущий запускает игру на своём мониторе: приложение автоматически размещает экран игроков на другом мониторе без переключения фокуса. Управление и просмотр ответа остаются у ведущего. Кнопка «Показ на втором экране» повторно открывает показ, если он закрыт.
За неверный ответ снимается стоимость вопроса. Повторное списание с той же команды за тот же вопрос заблокировано. «Отменить последнее» возвращает списанные баллы и возможность ответить.
Кнопка показа работает и без второго монитора: экран игроков открывается в обычном перемещаемом окне. Кнопка «Удалить тему» удаляет выбранную тему с вопросами из редактируемого шаблона; для записи изменений в БД нажмите «Сохранить».
Экран игроков между вопросами показывает табло с темами и баллами. Сыгранные ячейки приглушены, нажатия на табло игроков отключены. Выбор вопросов выполняется у ведущего.
